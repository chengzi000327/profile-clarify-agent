# 岗位画像澄清 Agent 前端原型

这是基于《岗位画像澄清 Agent PRD v0》和《前端方案 v0》制作的 React 交互原型，只包含前端演示状态，不包含真实后端、DeepSeek Harness 或人才库接口。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:5173/`。

生产构建：

```bash
npm run build
npm run preview
```

## 可以体验的流程

- 点击左侧 5 个岗位项目，切换 S-01～S-05 代表场景。
- 点击“创建岗位画像项目”，体验用人经理发起项目。
- 在 S-01/S-02/S-03/S-05 中选择回答并提交。
- 在 S-04 查看候选人证据矩阵和画像校准选项。
- 点击右侧“来源”进入证据视图。
- 在右侧“版本”分别模拟用人经理和 HR 确认，再发布 V0。
- 邀请 HR 加入后，从顶部切换为 HR 身份完成其独立确认；用人经理不能代替 HR 确认。
- S-03 存在关键冲突时发布保持禁用。
- 窄屏下使用底部“项目／对话／画像／证据／版本”切换。
- 新创建的项目提供“读取中／资料缺失／接口失败／会话恢复”四种原型状态切换。

## 文件说明

- `src/App.jsx`：页面组件和交互状态。
- `src/data.js`：Samples、岗位画像、证据和版本演示数据。
- `src/styles.css`：字节系视觉变量、桌面与移动端响应式样式。
- `dist/`：`npm run build` 生成的静态构建结果。

## 原型边界

- 页面刷新后交互状态会重置。
- 上传、资料获取、Agent 回复和项目保存均为前端模拟。
- 当前不包含登录、权限后台、真实协同通知和完整 ATS/HRIS 接口。
